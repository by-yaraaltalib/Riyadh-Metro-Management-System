# Riyadh Metro Management System

## Overview

Riyadh Metro Management System is a Java console application that simulates core metro operations. The system manages stations, passengers, ticketing, maintenance requests, and metro network operations using object-oriented programming and custom data structures.

## Features

- Manage metro stations and network connections
- Add and manage passengers
- Handle ticket requests using a queue system
- Search stations using a Binary Search Tree
- Manage metro lines using circular linked lists
- Prioritize maintenance requests using a heap structure
- Display metro system information through a console interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Data Structures
- Algorithms
- Console-Based Interface

## Data Structures Used

### Queue
Used for managing ticket requests in a first-in-first-out system.

### Binary Search Tree
Used for efficient station searching and directory management.

### Circular Linked List
Used to represent circular metro lines where stations connect continuously.

### Heap
Used to prioritize maintenance requests based on importance.

## Project Structure

- Station.java  
Represents metro station information.

- Passenger.java  
Stores passenger details.

- MetroNetwork.java  
Manages the metro network and connections.

- TicketingSystem.java  
Handles passenger ticket operations.

- MaintenanceSystem.java  
Manages maintenance requests.

- StationDirectory.java  
Provides station searching functionality.

- CircularLine.java  
Represents circular metro routes.
